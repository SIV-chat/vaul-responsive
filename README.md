# vaul-responsive

The package and its documentation live in [`packages/vaul-responsive`](packages/vaul-responsive/README.md).

## Development

```sh
bun install
bun run build       # the package
bun run dev:test    # Vite test app on :3000
bun run test        # build, then Playwright on iPhone and Pixel
bun run check       # types
bun run lint        # oxlint
bun run format      # oxfmt
```
